How this works

The canvas is an ordinary element styled with CSS (width: 100%; height: 86vh); ShaderMate sizes its bitmap to match and keeps it in sync on resize. The headline and buttons are normal DOM on top of it. The pointer still reaches the shader because ShaderMate listens on the window and maps coordinates into the canvas.

Hovering the primary button tweens u_hover, which raises the waves' amplitude and glow. u_scroll shifts the field as you scroll. Rendering pauses when the hero leaves the viewport or the tab is hidden, so the page stays cheap.
