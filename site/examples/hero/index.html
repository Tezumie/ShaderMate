How this works

Real page,
shader behind it.

Sized by CSS

The canvas is an ordinary element (width: 100%; height: 92vh). ShaderMate sizes its bitmap to match and keeps it in sync on resize.

DOM on top

The headline and buttons are normal HTML. The pointer still reaches the shader because ShaderMate listens on the window and maps coordinates into the canvas.

Cheap when idle

Hovering the button tweens u_hover; u_scroll adds parallax. Rendering pauses when the hero leaves the viewport or the tab is hidden.
