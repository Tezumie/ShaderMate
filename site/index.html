Fill a box, or the whole page

The shader follows a canvas's CSS size, or a full-window canvas is made for you.

createShader({ canvas: '#hero', shader });
createShader({ shader, size: 'window' });

React to the cursor

Track the pointer across the page, or only over one element.

pointer: { target: button, smooth: 0.2 }

Animate any value

Tween a uniform with easing. Vectors tween per component.

sm.tween('u_glow', 3, { duration: 600, ease: 'outCubic' });

Keep the last frame

Ping-pong float buffers for trails, feedback and simulations.

{ name: 'trail', pingpong: true, float: true, channels: ['trail'] }

Use media as a texture

A canvas, video, webcam, audio spectrum or image on any channel.

channels: [myCanvas, { video: 'clip.mp4' }, { camera: true }]

Save a still or a clip

Captures render a fresh frame, so no special context flags.

await sm.download('frame.png');
await sm.record({ duration: 5000, download: 'loop.webm' });

Stay quiet off-screen

Rendering pauses when the tab is hidden or the canvas scrolls away.

pauseWhenHidden: true,   // the default
maxFps: 30

Use it from React

Props update uniforms live without rebuilding the shader.

<ShaderCanvas shader={frag} uniforms={{ u_hover }} />

Tweak with sliders

Build a control panel from your uniforms in one call.

await createGui(sm);

Start in a minute.

// npm i shadermate
import { createShader } from 'shadermate';

createShader({
  canvas: '#hero',
  shader: `void main() {
    vec2 uv = gl_FragCoord.xy / u_resolution;
    fragColor = vec4(uv, 0.5 + 0.5 * sin(u_time), 1.0);
  }`,
});
<canvas id="hero"></canvas>
<script src="https://cdn.jsdelivr.net/npm/shadermate@2/dist/shadermate.min.js"></script>
<script>
  ShaderMate.createShader({ canvas: '#hero', shader: 'hero.glsl' });
</script>
// npm i shadermate
import { ShaderCanvas } from 'shadermate/react';

}
