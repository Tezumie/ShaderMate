07 · Custom uniforms

12 · Everything in the box

The line that
does it.

Fill a box or the page

Follows a canvas's CSS size, or makes a full-window canvas.

createShader({ shader, size: 'window' });

React to the cursor

Across the page, or only over one element.

pointer: { target: button, smooth: 0.2 }

Animate any value

Tween uniforms with easing, per component.

sm.tween('u_glow', 3, { ease: 'outCubic' });

Save a still or a clip

PNG screenshots and WebM recordings.

await sm.record({ duration: 5000 });

Stay quiet off-screen

Pauses when the tab is hidden or scrolled away.

pauseWhenHidden: true,  maxFps: 30

Use it from React

Props update uniforms without a rebuild.

<ShaderCanvas shader={frag} uniforms={{ u_hover }} />

Paste from ShaderToy

mainImage, iChannels and iMouse just work.

createShader({ shader: shadertoyCode });

Catch errors inline

Compile errors in an overlay, with line numbers.

errorOverlay: true   // the default

Share a canvas

Many shaders, one WebGL context. Swap with play/pause.

a.pause(); b.play();   // same canvas

// npm i shadermate
import { createShader } from 'shadermate';

createShader({
  canvas: '#hero',
  shader: `void mainImage(out vec4 o, in vec2 fc) {
    vec2 uv = fc / iResolution.xy;
    o = vec4(uv, 0.5 + 0.5 * sin(iTime), 1.0);
  }`,
});
<canvas id="hero"></canvas>
